# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them to Databricks Security at security@databricks.com, or through the Databricks bug bounty program on HackerOne: https://hackerone.com/databricks. We will acknowledge receipt of your vulnerability and strive to send you regular updates about our progress. If you're curious about the status of your disclosure please feel free to email us again.

If you want to encrypt your disclosure email, use the Databricks Security PGP key: https://www.databricks.com/.well-known/pgp-key.txt.

These are the contacts Databricks publishes in its security.txt (https://www.databricks.com/.well-known/security.txt); see also https://www.databricks.com/trust.
